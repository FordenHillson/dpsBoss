# Buff icons

วางไฟล์ `.png` ที่นี่ ชื่อให้ตรงกับ `id` ใน JSON

- Food: `public/buffs/food.json`
- Party: `public/buffs/party.json`

ตัวอย่าง:

```json
{
  "id": "candyBasket",
  "name": "Candy Basket / Cane",
  "stat": 30,
  "icon": "/buffs/icons/candyBasket.png"
}
```
